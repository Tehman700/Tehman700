## Open to work

Available for **backend / AI engineering roles** and **freelance API, cloud and infrastructure work**. Seven client codebases shipped to date — UK-market web platforms, an admin panel suite, a healthcare site and an affiliate marketing product.

**Software solutions.** A problem described in business terms comes back as a working system, not a prototype — data model, API contract, deployment, and the auth, permissions and error handling that decide whether it survives real users.

**Problem solving.** I go a layer below where the tutorial stops: my own ngrok written in Go, Perplexity's architecture rebuilt by hand, a RISC-V datapath in Verilog. It pays off when something breaks in production.

**System design & architecture.** Contract before code. On the school pickup system, two Android apps and a dashboard share one backend with an OpenAPI spec as the source of truth. I design around service boundaries, failure modes and the unhappy path — [notes here](https://github.com/Tehman700/System-Design-Engineering-Notes-Learnt-).

**Cloud & cost-efficient architecture.** AWS (EC2, S3, Route 53, load balancers) with Docker and GitHub Actions for build and release; currently working toward the **AWS CloudOps Engineer – Associate (SOA-C03)**. My bias is the simplest thing that meets the requirement — one right-sized instance and object storage beats a managed service most products never outgrow. Cheap to run for two years beats impressive and over budget in month one.

Fastest way to reach me: [LinkedIn](https://www.linkedin.com/in/tehman600/).
